# Checklist de Qualidade da Tarefa

Use antes de publicar ou considerar uma especificação pronta para execução.

## Objetivo e escopo
- [ ] O título descreve a mudança de forma direta.
- [ ] O problema ou a necessidade está explícito.
- [ ] O resultado esperado pode ser compreendido sem contexto oral.
- [ ] O escopo e as exclusões relevantes estão definidos.
- [ ] O tipo da tarefa é coerente com seu objetivo.

## Contexto técnico
- [ ] Os componentes afetados estão identificados quando conhecidos.
- [ ] Tecnologias e contratos citados foram confirmados.
- [ ] Regras de negócio e restrições relevantes estão documentadas.
- [ ] Premissas e informações não confirmadas estão identificadas.

## Critérios de aceite
- [ ] Cada critério é observável e verificável.
- [ ] O fluxo principal está coberto.
- [ ] Erros, limites e fluxos alternativos foram considerados quando pertinentes.
- [ ] Os critérios não prescrevem detalhes de implementação sem necessidade.
- [ ] Há condições claras para validar a conclusão.

## Execução e dependências
- [ ] Os passos sugeridos seguem uma ordem lógica.
- [ ] As dependências conhecidas estão registradas.
- [ ] Os riscos relevantes foram identificados.
- [ ] Os testes e as evidências esperadas foram considerados.
- [ ] A documentação relacionada foi considerada.

## Bloqueadores
- [ ] Não há decisões críticas ocultas.
- [ ] Dúvidas essenciais foram respondidas ou registradas como bloqueadoras.
- [ ] Não há afirmações técnicas sem fundamentação.

## Prévia e gravação
- [ ] A pessoa confirmou se quer todas as etapas detalhadas ou somente os principais marcos.
- [ ] A especificação completa foi apresentada como prévia ainda não salva.
- [ ] O caminho proposto em `tarefas/` foi informado e não sobrescreve arquivo existente.
- [ ] A versão que será gravada recebeu aprovação explícita.
- [ ] O arquivo salvo corresponde exatamente à prévia aprovada.

## Resultado da revisão
- **Pronta:** informações suficientes para iniciar.
- **Pronta com pendências:** é possível iniciar sem comprometer decisões críticas.
- **Bloqueada:** faltam informações ou decisões essenciais.

Registrar o motivo do resultado quando houver pendências ou bloqueios.
