# Tarefas aprovadas

Esta pasta guarda as especificações de tarefas aprovadas para gravação pela
skill Planejador de Tarefas. Cada tarefa fica em seu próprio arquivo Markdown.

## Regras de gravação

- Mostrar primeiro a especificação completa no chat como prévia ainda não salva.
- Criar ou atualizar arquivo somente após aprovação explícita daquela prévia.
- Salvar exatamente o conteúdo aprovado; alterações posteriores precisam de
  nova prévia e aprovação.
- Usar o padrão `AAAA-MM-DD-titulo-em-kebab-case.md`.
- Não sobrescrever arquivos existentes; se um caminho ficar ocupado depois da
  prévia, propor nome com sufixo numérico e pedir nova aprovação antes de salvar.
- Manter todas as especificações aprovadas nesta pasta.

Esta pasta não contém uma tarefa de exemplo: exemplos da skill são ilustrativos
e não representam solicitações aprovadas.
